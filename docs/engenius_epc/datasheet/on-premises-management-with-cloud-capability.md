# On-premises Management With Cloud Capability

## <mark style="color:blue;">Overview</mark>

EnGenius Private Cloud (EPC) is an on-premises network management solution that combines local control with optional cloud integration.

Designed to meet the needs of businesses of all sizes—from neighborhood shops to enterprise IT teams—EPC delivers advanced features and scalability without compromising data sovereignty.

By keeping network telemetry and configurations on your own server and syncing only when you choose, EPC offers the flexibility of the cloud with the security and customization of an in-house solution.<br>

## <mark style="color:blue;">Highlights</mark>

* **Easy Deployment** — A guided Windows installer enables non-technical users to install EPC in minutes. For organizations with established DevOps practices, a Docker option ensures consistent, containerized deployments.
* **Designed for All Users** — EPC is built for businesses of every size. A clear web interface allows anyone—from small store owners to seasoned IT administrators—to manage networks without specialized training. Intuitive dashboards, charts, and real-time alerts make network management effortless.
* **Free Baseline Features** — EPC’s core capabilities, including device monitoring, configuration, and basic security via an intuitive graphical interface, are available at no upfront cost—helping small businesses and startups manage networks effectively and affordably.
* **Data Sovereignty** — All network data stays on-site. EPC communicates with EnGenius Cloud only for license synchronization and firmware updates, ensuring privacy and regulatory compliance.
* **Scalable** — A single EPC server can manage up to 3,000 devices, supporting multiple organizations or departments within one platform. As your network grows, EPC grows with you.
* **Broad Product Support** — EPC supports a wide range of EnGenius wireless access points and switches, with backward compatibility for previous-generation devices.
