## Review Checklist For Future Cleanup

Use this checklist before accepting source changes that touch these paths:

1. Confirm whether the path is generated by OpenTofu, Packer/Butane, Ansible, or
   coverage tooling.
2. Check `git ls-files <path>` before deciding whether the file is already
   tracked or only a local artifact.
3. For tracked examples, decide explicitly whether the repository wants a
   sanitized fixture, a generated output, or no file at all.
4. Keep state files, provider caches, active local env files, and coverage output
   out of routine commits.
5. Do not combine ignore-rule changes, file deletions, and fixture migrations
   with unrelated feature work.
